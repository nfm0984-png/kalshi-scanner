# Kalshi Scanner

A Kalshi sports-whale board for Noel: Coming Up (one card per game, soonest start first), Ranked (combined capper record + today's $40 card), and Cappers.

Data comes from Kalshi's public social and trade APIs. There is no 30-day leaderboard period; monthly is the closest stand-in. Most top traders hide their book, so only public profiles are used. Win-loss records are reconstructed from the public sports trade tape and are never invented.

Suggested stakes are $2–4 a ticket, about $40 a day. No parlays. Nothing is placed for you.
